# Contributing

Install Node.js 20+, FFmpeg, and dependencies with `npm install`. Run `dumbeditor setup` after building, or create `.env` from `.env.example`, then run `npm run quality` before opening a change.

Keep direct edits deterministic and reversible. Add a new JEV route only when the operation has a bounded parameter shape that code can validate. Use the agent route for custom multi-step work.

Never commit API keys, source videos, rendered versions, or agent workspaces.
